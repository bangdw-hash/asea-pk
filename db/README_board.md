# 전광판 입력판 (board-input.html) 설치·사용 안내

## 구성
| 파일 | 역할 |
|---|---|
| `board.html` | TV 화면. 주요 안내는 내용 높이에 맞춰 자동으로 페이지를 나눔(건수 제한 없음, 문구 전체 표시, `1/3` 쪽번호 + 하단 진행선). 오른쪽 아래 작은 톱니, 주소 뒤 `?admin`, `Ctrl+Shift+A` 중 하나로 화면 직접 편집 모드 진입 |
| `board-input.html` | 입력 전용 화면(주요 안내·환영 문구·슬라이드·시설 대관) |
| `board-admin.js` | 입력판과 TV 편집 모드가 함께 쓰는 편집 화면(목록·폼·저장·이전 저장본) |
| `board-db.js` | Supabase 연결, 시트별 변환, TV용 데이터 덮어쓰기 |
| `db/board_schema.sql` | Supabase `brd` 스키마와 RPC(`brd_get/login/save/hist/restore/setpw`) |

## 동작 원칙
- **DB에 저장된 시트만** DB 내용을 사용합니다. 저장 전인 시트는 기존 구글시트/Apps Script 경로를 그대로 씁니다. 그래서 시트별로 하나씩 옮길 수 있습니다.
- 읽기는 누구나(화면 표시 내용만 저장), 쓰기는 비밀번호 로그인 후 받은 12시간짜리 토큰이 있어야 합니다. 10분 안에 8번 틀리면 잠깁니다.
- 저장은 시트 단위이며 버전 확인(다른 곳에서 먼저 저장했으면 충돌 안내)과 이력 보관을 거칩니다. 「이전 저장본」에서 되돌릴 수 있습니다.
- TV는 마지막 정상 데이터를 브라우저에 보관하므로 인터넷이 잠시 끊겨도 화면이 비지 않습니다.

## 처음 옮기는 순서
1. `board-input.html` 접속 → 로그인(초기 비밀번호는 전달받은 값) → **비밀번호 변경**
2. 시트 탭(주요 안내 등)에서 **구글시트에서 가져오기** → 내용 확인 → **저장**
3. 저장한 시트부터 TV가 DB 내용을 사용합니다(최대 30초). 환영·슬라이드·서체는 기존 화면 로직이 그대로 읽습니다.
4. 서체·화면 설정·테마 순환은 입력판이 아니라 TV 화면 편집 모드(`board.html?admin`)의 도구줄에서 수정합니다.

## 주요 안내 규칙
- 표시초는 1~3페이지에만 직접 지정하고 0이면 글자 수에 따라 6~20초로 자동 정합니다(4페이지부터도 자동).
- 종료일을 비우면 문구 속 날짜(예: `10/23`)를 종료일로 보고 다음 날 자동으로 내립니다. 목록에 `자동 ~10-23`으로 표시되며, 「종료일과 관계없이 계속 게시」를 켜면 내리지 않습니다.
- 한 건이 한 페이지보다 길면 그 페이지만 글자를 줄여(최소 70%) 전체를 표시합니다.

## 되돌리기(시트 방식으로 복귀)
특정 시트를 다시 구글시트로 쓰려면 Supabase SQL 편집기에서 해당 행을 지웁니다(삭제 확인 필요).
`delete from brd.sheets where name = 'notice';` (이름: notice, welcome, slides, rental, fonts, settings, theme)

## 알려진 한계
- 만료된 로그인 토큰, 실패 기록, 30개를 넘는 이력은 자동 정리하지 않습니다(용량이 매우 작음). 필요하면 SQL 편집기에서 정리합니다.
- 대관 슬라이드의 순환/고정 모드는 반영하지 않습니다(항상 순환).
